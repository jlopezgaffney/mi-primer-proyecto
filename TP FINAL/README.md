La idea de este proyecto es cargar los datos del relevamiento de precios mayoristas. La idea es que a medida que vaya pasando el tiempo, y se vayan agregando mas datos poder ir haciendo predicciones y analisis mas precisas.

1)Los datos se obtienen mediante la pagina del gobierno: https://www.datos.gob.ar/dataset/precios-claros-sepa-mayorista
